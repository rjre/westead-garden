# Westead Garden Almanac

A single-file, self-contained garden almanac for Westead.

- Opens on the current week with a tick-off job list
- Live 7-day weather for the garden (Open-Meteo) with frost / drought / gale advisories
- Full plant directory with photos (Wikipedia), care notes and a 12-month activity band
- Pick any month to plan ahead

Hosted with GitHub Pages — everything lives in `index.html`.
To update: edit `index.html`, commit, push. Pages redeploys automatically.
